## Data Storage

**Databases:**
- MySQL 8.4 (`mysql:8.4` in `compose.dev.yaml`)
  - Connection: built from env vars in `database/database.js`: `PROD_MYSQL_USER`, `MYSQL_PASSWORD`, `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_NAME`. Built as a `mysql://` URL with no URL-encoding of the password.
  - Client: `drizzle-orm` `1.0.0-rc.4` with `mysql2` `3.24.4` (`drizzle(mysqlUrl, { relations })` in `database/database.js`)
  - Schema: table definitions in `app/models/*.js` (e.g. `app/models/users.js`, `app/models/sales.js`, `app/models/inventory-batches.js`), relations in `app/models/relations/relations.js`
  - Migrations: generated SQL in `database/migrations/20260926024159_steep_nico_minoru/` and `database/migrations/20260926061918_tan_rattler/`, with snapshots. Generated by `drizzle-kit` using `drizzle.config.js`.
  - Migration runner: **missing**. The `migrate`, `migrate:fresh`, `migrate:drop` npm scripts point to `src/scripts/migrate/*.js`, which do not exist.
  - Known issues:
    - `database/database.js` is not imported by the running app (`src/app.js` and `routes/` do not use it). Its `mysqlDb` export is not exported at all.
    - `src/scripts/create/model.js` line 15 contains `import { sequelize } from "../../database/database.js"`. `database/database.js` exports no `sequelize`.
    - Connection credentials in `drizzle.config.js` are hard-coded (`localhost`, port `3306`, user `root`, literal password) rather than read from env.
- Redis 8.10.2 (`redis:8.10.2` in `compose.dev.yaml`, with `REDIS_HOST`/`REDIS_PORT`/`REDIS_PASSWORD` in `.env.example`)

## Authentication & Identity

**Auth Provider:**
- Custom, no third-party identity provider (no OAuth, OIDC, Passport, or JWT library).
  - Implementation: session cookie with `req.session.userId` set in `app/http/controllers/authController.js`. Session secret from `SECRET_KEY` (fallback `development-secret`) in `src/app.js`.
  - Password hashing: `argon2` `0.45.1`. `register` hashes `password + salt + pepper` where `salt` is a `uuid` v4 and `pepper` is `process.env.SECRET_KEY` (`app/http/controllers/authController.js`). Argon2 parameters come from `config/cryptography.js`.
  - Login verification is incomplete: the `argon2.compare` call is commented out, and `login` references `user` and `match` which are never defined in that scope.
  - Register flow is incomplete: `register` references an undefined `password` variable and does not persist the user to MySQL.
  - Route guard: `dashboardPage` checks `req.session.userId` and redirects to `/login`. Logout calls `req.session.destroy()`.
  - Input validation: `zod` schemas in `app/http/requests/auth/loginRequest.js` and `registerRequest.js`.
- `bcrypt` is declared in `package.json` but not used by code.
